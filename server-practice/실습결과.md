# 09. 서버 만들기 실습 결과

- 실행 환경: Node.js v26.13.1 (Windows)
- 실행 방법: 터미널에서 `node 파일이름.js` → 브라우저에서 `http://localhost:3000` 접속 → 종료는 `Ctrl+C`
- 각 실습의 실제 터미널 출력은 `결과` 폴더에 저장되어 있습니다.

---

## 실습 1. 서버 만들기 (`01-server.js`)
`http.createServer()`로 서버를 만들고 `server.listen(3000)`으로 실행

**터미널 출력**
```
3000번 포트에서 서버 실행 중
요청 발생
```
- 브라우저로 접속하면 "요청 발생"이 찍힙니다.
- 응답(`res.end()`)을 보내지 않기 때문에 브라우저는 계속 로딩 상태로 기다립니다.

## 실습 2. 요청 객체 살펴보기 (`02-request.js`)
`console.log(req)`로 요청 객체 전체를 출력

**터미널 출력 (앞부분)**
```
3000번 포트에서 서버 실행 중
<ref *2> IncomingMessage {
  _events: { ... },
  _readableState: ReadableState { ... },
  ...
```
- 요청 객체는 `IncomingMessage` 타입이고, 출력이 약 570줄에 이릅니다. 전체는 `결과/02-request-터미널.txt`에 있습니다.
- 그 안에 `method`, `url`, `headers` 같은 요청 정보가 들어 있습니다.

## 실습 3. 응답 객체 (`03-response.js`)
`res.setHeader()` → `res.write()` → `res.end()`

| 요청 | 브라우저 결과 |
|---|---|
| GET http://localhost:3000/ | `Hello Node` |

**터미널 출력**
```
3000번 포트에서 서버 실행 중
GET
GET
```
- `req.method`가 출력됩니다. 브라우저가 페이지와 아이콘(favicon)을 따로 요청하기 때문에 GET이 2번 찍힙니다.

## 실습 4. HTML 페이지 응답 (`04-html.js`, `index.html`)
`fs.createReadStream()`으로 `index.html`을 읽고 `pipe(res)`로 응답

| 요청 | 브라우저 결과 |
|---|---|
| GET http://localhost:3000/ | 제목 "Node.js 서버 실습" 페이지, 본문 "Node.js 서버에서 보낸 HTML 페이지입니다" |

- `Content-Type`을 `text/html`로 지정했기 때문에 브라우저가 글자 그대로가 아니라 HTML로 해석해서 보여 줍니다.

## 실습 5. 라우팅 (`05-routing.js`)
요청 메서드와 URL에 따라 다른 응답을 보냄

| 요청 | 상태 코드 | 응답 본문 |
|---|---|---|
| GET /home | 200 | `HOME` |
| GET /about | 200 | `ABOUT` |
| GET /contact (정의되지 않은 주소) | 404 | `NOT FOUND` |

- **수정한 점:** 슬라이드의 라우팅 코드에는 `server.listen()`이 빠져 있어서, 그대로 실행하면 서버가 켜지지 않고 바로 종료됩니다. 그래서 `server.listen(3000, ...)`을 추가했습니다.
